# Contributing

Thanks for helping keep the IENN site up to date.

## Suggesting a content update

If you'd like to submit a news item, an event, or a correction/update to any
page (Home, About, Mailing List, News & Events), please open an
[Issue](https://github.com/ELIXIR-IE/esfri-ireland/issues/new/choose) using
the **Content update or submission** template. It asks for:

- Which page/area it relates to
- What kind of change it is (new news item, new event, correction, other)
- A description of the change

If your request doesn't fit that template, you're welcome to open a blank
issue instead — describe what you'd like changed and we'll follow up.

## Submitting changes directly

If you have write access to the repository, you can also open a Pull Request
directly against the relevant file in `src/pages/`.

## Local development

See the [README](README.md#local-development) for how to run the site
locally before submitting a change.
